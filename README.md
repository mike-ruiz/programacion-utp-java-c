## Proyectos

### Sistema de Reserva de Vuelos — Java (POO)

Aplicación de consola para registrar vuelos, reservar asientos y consultar reservas, con simulación de pago.

- **Clases:** `Vuelo`, `Asiento`, `Pasajero`, `Reserva`, `Pago`, `Ticket` y `SistemaReservaVuelos` (menú principal).
- **Funciones:** ver vuelos, reservar un vuelo, ver reservas y registrar vuelos nuevos.
- **Validaciones:** códigos de vuelo únicos, datos obligatorios, asientos ocupados, pagos no válidos y entradas numéricas.
- **Conceptos:** encapsulamiento, composición entre clases, arreglos de objetos y control de flujo.

### Sistema de Facturación — C

Programa de consola para generar facturas.

## Tecnologías y conceptos

- **Lenguajes:** Java, C / C++
- **Paradigmas:** programación estructurada y orientada a objetos
- **Estructuras de datos:** arreglos, listas enlazadas, árboles binarios de búsqueda, colas
- **Fundamentos:** estructuras selectivas y repetitivas, validación de entradas, manejo de memoria dinámica, recursividad
- **Herramientas:** JDK, compilador C++ (g++), Git y GitHub

## Cómo ejecutar

**Java**

```bash
cd proyectos/SistemaReservaVuelos
javac *.java
java SistemaReservaVuelos
```

**C / C++**

```bash
cd proyectos/Sistema-Facturacion
g++ biblioteca.cpp -o biblioteca
./biblioteca
```

> Requisitos: JDK 17 o superior y un compilador de C++ (g++ / MinGW).
